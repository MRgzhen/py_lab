# opencv_lab

OpenCV 学习实验代码。依赖见 `requirements.txt`（numpy、opencv-python、matplotlib 等）。

## 环境搭建

### 1. 用 conda 创建虚拟环境

```bash
conda create -n opencv_lab python=3.10
```

### 2. 切换到虚拟环境

```bash
conda activate opencv_lab
```

退出虚拟环境：

```bash
conda deactivate
```

### 3. 用 pip 安装依赖

```bash
pip install -r requirements.txt
```

## 运行示例

```bash
cd opencv_lab
python chapt/learn01.py
```
